# Murtza
> AURA LAB // High-Performance Luxury Athletic Wear E-Commerce & Operations Platform
> Design Source: Stitch Project ID `12378250600321310020`

## Overview
This repository contains the complete frontend for AURA LAB / Apex Activewear:
- **Customer Storefront (`index.html`)**: Dynamic hero crossfade carousel, curated disciplines, featured product matrix, interactive quick-add, slide-over cart drawer with threshold progress bar.
- **Product Detail Page (`product.html`)**: 4-angle gallery switcher, size/color matrix, quantity selector, technical accordions.
- **Categories Explorer (`categories.html`)**: Discipline filtering, sorting, responsive catalog grid.
- **Operations Back-Office (`admin/`)**: 8 complete admin pages (Dashboard, Products, Product Edit Studio, Categories, Orders, Customers Dossier, Analytics, Settings).
- **Core Engine (`js/`)**: Cart management (localStorage), Wishlist, Toasts, Drawer handlers.
- **Styles (`css/style.css`)**: Frosted glassmorphism, Space Grotesk / Inter typography, custom scrollbars.
